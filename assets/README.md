# الهوية والمواد البصرية

يُستخدم هذا المجلد للشعارات والمواد البصرية المسموح بنشرها بعد إعدادها.
لا توجد هوية نهائية معتمدة ضمن هذه البداية.

عند إضافة مادة، وثّق اسمها ومصدرها وحقوق استخدامها وحالة اعتمادها، وأرفق النسخة القابلة للتحرير إن توفرت.
لا ترفع صور أشخاص أو وثائق شخصية دون صلاحية مشاركة مناسبة.
