# neuoronco | فريق الأعصاب والأورام

مساحة عمل لتنظيم تأسيس فريق طلابي يهتم بالأعصاب والأورام وتقاطع المجالين، وتحويل الأفكار إلى مبادرات تعليمية وتوعوية ومشاريع بحثية يمكن متابعتها وتطويرها.

> **الحالة: بداية تنظيمية مقترحة.** أسماء المسارات واللجان والأدوار وآلية الاعتماد قابلة للتعديل، ولا تمثل هيكلًا قياديًا أو انتسابًا مؤسسيًا معتمدًا.

## الهدف

- تنمية معرفة الطلبة ومهاراتهم في الأعصاب والأورام.
- إعداد أنشطة توعوية بمحتوى موثق ومراجع قبل النشر.
- دعم التدريب والتعاون البحثي تحت الإشراف المناسب.
- توثيق الخطط والنتائج والدروس المستفادة لتسهيل انتقال العمل بين الأعضاء.

## المسارات العلمية المقترحة

| المسار | نطاق العمل المقترح |
| --- | --- |
| الأعصاب | أنشطة تعليمية وتوعوية في علوم الأعصاب وصحة الجهاز العصبي |
| الأورام | أنشطة تعليمية وتوعوية في علوم الأورام ودعم الوعي المجتمعي |
| أورام الجهاز العصبي | أنشطة مشتركة تربط الأعصاب بالأورام |

هذه مجالات محتوى وليست مناصب أو لجانًا ثابتة. تُنفذ عبر المبادرات والفعاليات والأبحاث، ويمكن دمجها أو تغييرها وفق قرار الفريق.

## ابدأ بأول نشاط

1. اختر [قالب مبادرة](templates/initiative.md)، أو [فعالية](templates/event.md)، أو [مشروع بحثي](templates/research-project.md).
2. انسخه إلى مجلد النوع المناسب باسم واضح؛ مثل `initiatives/neuro-awareness.md`.
3. املأ الحقول المعروفة واترك غير المحسوم بصيغة «يُحدد لاحقًا». ابدأ بالحالة «مسودة».
4. افتح طلب تعديل (Pull Request) وفق [دليل المساهمة](CONTRIBUTING.md)، وحدد المطلوب مراجعته.
5. حدّث الملف عند تغير الحالة، ثم أضف النتائج الفعلية والدروس المستفادة بعد التنفيذ.

## المتابعة والقرارات

حالات العمل المقترحة: **مسودة ← قيد المراجعة ← معتمد للتنفيذ ← قيد التنفيذ ← مكتمل**؛ ويمكن استخدام «مؤجل» أو «ملغى» مع السبب.
دمج ملف في المستودع لا يعني اعتماد النشاط أو الموافقة على البحث.

ابدأ من [خطة التأسيس](docs/roadmap.md)، وسجّل ما لم يُحسم في [سجل القرارات](docs/decisions.md).

## المحتوى والخصوصية

هذا المستودع عام. تُحفظ فيه الخطط والمواد المناسبة للنشر فقط، دون بيانات مرضى أو إجابات مشاركين أو قوائم حضور أو معلومات تواصل شخصية.
المحتوى التعليمي يحتاج مراجعة علمية ومراجع موثوقة قبل نشره للجمهور. لا يُعد المستودع مصدرًا للاستشارة الطبية.
