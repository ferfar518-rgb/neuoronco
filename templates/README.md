# القوالب

| القالب | يُنسخ إلى | متى يستخدم؟ |
| --- | --- | --- |
| [مبادرة](initiative.md) | `initiatives/` | حملة أو عمل له هدف وقد يضم عدة فعاليات |
| [فعالية](event.md) | `events/` | دورة أو ورشة أو لقاء محدد |
| [مشروع بحثي](research-project.md) | `research/` | فكرة بحث أو بروتوكول أولي |

انسخ القالب واترك الأصل فارغًا لإعادة الاستخدام. استبدل الحقول بين الأقواس، واستخدم «يُحدد لاحقًا» للمعلومات غير المعروفة و«لا ينطبق — السبب» لما لا ينطبق.
يمكن حذف الأقسام غير اللازمة أو إضافة أقسام جديدة. القوالب لا تمنح موافقة تنفيذية أو بحثية.
