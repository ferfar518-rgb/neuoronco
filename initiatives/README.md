# المبادرات والحملات

هذا المجلد مخصص لملفات المبادرات والحملات. لا توجد أنشطة معتمدة مضافة بعد.

1. انسخ [القالب](../templates/initiative.md) إلى هذا المجلد باسم وصفي.
2. ابدأ بحالة «مسودة»، وحدد الهدف والمسؤول والمخرجات المتوقعة.
3. حدّث الحالة والمهام والنتائج في الملف نفسه.
4. إذا توسع العمل، يمكن نقله إلى مجلد فرعي مع تحديث الروابط.

راجع [دليل المساهمة](../CONTRIBUTING.md) قبل رفع التعديلات.
