# مبادئ العمل والأدوار المؤقتة

الحالة: مقترح قابل للتعديل.

## تنظيم العمل

تُدار الأعمال حاليًا حسب النشاط، مع تحديد مسؤول لكل مخرج. يمكن أن يؤدي الشخص أكثر من دور بحسب حجم العمل؛ لا تُنشئ هذه الوثيقة تعيينات أو صلاحيات قيادية نهائية.

| الدور على مستوى النشاط | المسؤولية المقترحة |
| --- | --- |
| منسق النشاط | تحديث الخطة ومتابعة المهام والتنسيق |
| المساهم | تنفيذ مهمة محددة وتوثيق مخرجها |
| المراجع العلمي عند الحاجة | مراجعة دقة المحتوى ومصادره |
| مسؤول اعتماد النشاط | يُحدد لاحقًا وفق الجهة المشرفة ونوع النشاط |

## قواعد تشغيل أولية

- لكل نشاط هدف واضح، وفئة مستهدفة، ومسؤول متابعة، ومؤشر نتيجة.
- تُكتب الأدوار بأسماء وظيفية حتى يتم الاتفاق على الأعضاء.
- يُذكر سبب التأجيل أو الإلغاء ويُحفظ ملخص النتائج عند الإغلاق.
- توثّق الموافقات المطلوبة قبل التنفيذ، والمراجعات العلمية قبل النشر.
- تُرفع البيانات الحساسة في الأنظمة المعتمدة لدى الجهة المشرفة فقط؛ لا تُرفع هنا.

## موضوعات غير محسومة

الهيكل القيادي، أسماء اللجان، شروط العضوية، آلية الشهادات والنقاط، الجهة المشرفة، والميزانية.
تُناقش وتُوثق في [سجل القرارات](decisions.md)، ولا تُفترض ضمن القوالب.
